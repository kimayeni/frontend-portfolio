Contributing Guidelines

Thank you for your interest in contributing to this project.

How to Contribute
1. Fork the repository.
2. Create a new branch for your changes.
3. Make your changes clearly and carefully.
4. Write clear commit messages.
5. Submit a pull request for review.

Code Style
- Use semantic HTML.
- Keep code clean and well-structured.
- Comment code where necessary.

Reporting Issues
If you find a bug or have a suggestion:
- Open an issue on GitHub
- Clearly describe the problem or idea

Contributions Scope
This project is mainly for learning purposes.
Major changes should be discussed before submission.

Code of Conduct
All contributors are expected to be respectful and professional.
